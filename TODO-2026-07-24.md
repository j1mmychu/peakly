## 4. Code — known bugs I did NOT fix (deliberate; each needs a decision or its own test pass)

- [ ] 🔴 **APNS will deliver zero pushes if wired today** — two independent defects in `server/proxy.js`: the ES256 JWT signs with DER encoding (Apple needs raw R‖S → `dsaEncoding: 'ieee-p1363'`), and `firePush` uses global `fetch`, which is HTTP/1.1-only while APNs is HTTP/2-only (needs the `http2` module). **Fix both before touching the .p8.** Not urgent — push is gated off for iOS v1.
- [ ] **Alerts API has no auth and guessable `Date.now()` ids** — anyone can delete or hijack another user's alert, or fill all 10,000 slots. Fix: client-generated UUID as the alert id (capability token) + reject POSTs that overwrite an existing id with a different push token. Must land before push ships.
- [ ] **Trans-dateline day misalignment** — `timezone=auto` returns venue-local days but indices come from user-local "today," so **Asia/Pacific venues are off by one day for US evening users**. Proper fix is anchoring indices by ISO date lookup in `wx.daily.time` instead of by offset (~15 lines, deserves its own test pass).
- [ ] **Low-confidence scores rank undiscounted** in the default grid sort (carousels filter correctly). A low-confidence day-12 score of 82 outranks a high-confidence 78.
- [ ] **Mid-week users can never see a next-weekend pick** — confidence is graded by the window's *worst* day, so Tue/Wed/Thu always grades weekend 2 as "low." Consider grading by the best pair's max day index.
- [ ] **Splash is never dismissed on a pre-mount failure** — it's only removed inside App's first effect, so any Babel/CDN failure leaves users staring at it forever, with the "Retry" fallback rendering *underneath* it. Two-line fix + a watchdog timeout.
- [ ] **The global "Unexpected token" handler can destroy the running app** — it fires on any uncaught error containing that string (e.g. a stray `JSON.parse`) and rips out the React tree post-mount. Gate it on not-yet-mounted.
- [ ] **BASE_PRICES covers a minority of airports** — the rest run deal math on coarse continent-pair estimates, including CUN (8 venues), IBZ (7), HKT (6), MIA, LAX. Backfill the top ~15 by venue count; the deal score is a headline feature and it's currently guessing on Cancún.
- [ ] **`poolPrimary` is dead** — documented in CLAUDE.md, implemented in `scoreVenue`, set on zero venues. Either populate it or delete the branch.
- [ ] **SRI + CSP on CDN scripts** (agents' standing P2) — now feasible since Babel is pre-compiled out of production.
- [ ] Housekeeping: `.fuse_hidden0000001100000001` got committed (filesystem artifact) — delete + gitignore.
