## One Product Risk Nobody Is Talking About

**The product is 9,095 lines and growing, but zero users have validated any feature shipped since May 3.**

The pivot, the scoreWeekend rewrite, MapView, BookingConfirmSheet, Alerts Quick Templates, the UI polish — all shipped, none human-tested beyond the Playwright smoke script. That script catches "does it render?" — not "does the score make sense for my airport?", "does the filter CTA actually appear when I set ≤4hr flights?", or "does the Booking.com link go somewhere real?"

The Reddit post is the first real user test. A broken pricing proxy, an empty Explore grid for an obscure home airport, or a BookingConfirmSheet that reads as "we don't trust our own partners" will show up in the first comment. The mitigation is a 5-minute human click-through before the post goes out. That's it. It's the only real QA gate between here and the launch.
