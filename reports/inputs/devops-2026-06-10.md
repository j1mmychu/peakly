## 3. P0 — GitHub PAT expires 2026-06-15 (5 days)

**Correction to yesterday's report, which overstated the blast radius:**

- GitHub Pages deploys do **NOT** depend on the PAT — `.github/workflows/deploy.yml` uses the auto-provisioned workflow token (`permissions: pages: write, id-token: write`, `actions/checkout@v4` default auth). It rotates automatically.
- Local pushes do **NOT** depend on it either — push is SSH-only (`git@github.com:j1mmychu/peakly.git`, per CLAUDE.md).
- What the PAT (`peakly-vps-deploy`) actually gates: the **VPS-side `git pull`** in `/opt/peakly-proxy` (and `deploy-chain.sh`'s SSH leg), if its remote embeds the PAT. An expired token in an HTTPS remote URL fails auth even on a public repo.

So expiry breaks the **VPS deploy path only** — site keeps deploying, local pushes keep working. Still renew it; it's 3 minutes:

```
1. github.com/settings/tokens → token "peakly-vps-deploy" (expires 2026-06-15)
2. Regenerate → 1-year expiry → copy
3. ssh root@198.199.80.21
   cd /opt/peakly-proxy
   git remote set-url origin https://j1mmychu:<NEW_TOKEN>@github.com/j1mmychu/peakly.git
   git pull   # verify it authenticates
```

Alternative that kills this annual chore: switch the VPS remote to plain public HTTPS with no token (`git remote set-url origin https://github.com/j1mmychu/peakly.git`) — pulls on a public repo need no auth at all. Then delete the PAT and retire the `peakly-token-renewal` watcher. Recommended.

## 8. What Breaks First at Scale

The single point of failure is now the **1GB VPS proxy itself**, not Open-Meteo. While it's up, the 2hr shared cache flattens weather load through 100K MAU. If it goes down under load, every client falls back to direct Open-Meteo with no back-off (§5 cooldown gap) and the free tier evaporates in minutes — users see a silently blank grid. Prevention is two small things, not one big one: ship the `_proxyWxFailedAt` cooldown (15 min, client-side), and put an UptimeRobot ping on `/health` (known-skipped, but it's the 5-minute external-account task that makes a proxy outage a page instead of a mystery).
